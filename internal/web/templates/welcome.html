Set up vx

Three steps from here to agents working in your repositories.{{with .GitHubLogin}} You are signed in as GitHub user {{.}}.{{end}}

  1. Install the vx GitHub App on your organization

    vx reads repositories and roles through the App, and opens pull requests with it. People keep the access they have on GitHub.

    {{if .InstallURL}}

    Install the GitHub App

    {{else if .SiteAdmin}}

    This server has no GitHub App yet. You are a site admin: create it once for the whole server, then this button installs it.

    Set up the GitHub App

    {{else if .GitHub}}

    The install link is not available yet. Ask a site admin to check Admin > GitHub.

    {{else}}

    This server has no GitHub App yet. A site admin sets it up on Admin > GitHub.

    {{end}} {{if .Installations}}

    Installed on:

      {{range .Installations}}
    • {{.AccountLogin}}{{if eq .AccountType "User"}} (personal){{end}}{{if .SuspendedAt}} (suspended){{end}}
      • {{end}}
    {{end}}

  2. Install the CLI

    curl -fsSL {{.Server}}/install.sh | sh

  3. Sign in the CLI and add the Claude Code plugin

    vx login --server {{.Server}}

    It opens your browser; you approve the sign-in there. No token to copy.

    Then, in Claude Code:

    /plugin marketplace add TerracodeBA/vx
/plugin install vx@vx
